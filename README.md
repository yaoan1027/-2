## 🧩 核心功能模組

### 1. 世界人口預測 (UN WPP 基準)
- **2024**: 81.6 億 (現況基期)
- **2030**: 85.2 億 (+4.4%)
- **2050**: 97.1 億 (+19.0% 關鍵峰值期)
- **2100**: 103.5 億 (長期趨緩平原期)

### 2. 伊朗地緣政治風險 (嚴格區分「事實資料」與「分析推論」)
1. **荷莫茲海峽咽喉控制**：
   - *事實*：日承載全球 20% 石油運輸，伊朗部署反艦飛彈與快艇。
   - *推論*：實質封鎖或扣船將引發布蘭特原油單週暴漲 25-35% 避險溢價。
2. **濃縮鈾純度與核臨界點**：
   - *事實*：IAEA 監控確認濃縮鈾純度已達 60%，逼近 90% 武器級門檻。
   - *推論*：跨越門檻恐誘發先發制人空襲與區域軍備競賽。
3. **抵抗軸心（代理人體系）動員**：
   - *事實*：葉門青年運動及真主黨常態獲無人機與反艦技術轉移。
   - *推論*：海運繞道好望角常態化，倍增航運週期與保費，加劇通膨。
4. **國內高通膨與政權接班壓力**：
   - *事實*：貨幣重貶、通膨長期大於 35%，領導層換屆逼近。
   - *推論*：保守派為轉移內部經濟不滿，傾向提高對外軍事冒險頻率。

### 3. 方法論：AI 協作與資料驗證
- **AI 應用**：利用 LLM 梳理跨維度因果分析矩陣、輔助生成乾淨無贅言之前端結構。
- **資料驗證**：人口指標對齊聯合國 UN DESA (2024 Revision)；地緣數據對齊 IAEA 及 EIA 公開監測資料，杜絕 AI 幻覺。
